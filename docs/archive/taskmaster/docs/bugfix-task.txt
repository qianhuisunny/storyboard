# Bug Fix Task: TopicResearcher Utility Functions

## Task: Verify and Fix TopicResearcher Utility Functions

### Description
The TopicResearcher agent has utility functions for parsing user-provided materials (PDFs and links) that may not be working correctly. These functions are used to extract content from user uploads during the research phase.

### Details
1. **PDF Parser** (`_parse_pdf` or similar):
   - Check if PDF parsing is implemented and working
   - Verify it extracts text content from uploaded PDFs
   - Test with sample PDF files
   - Check error handling for corrupted/invalid PDFs

2. **Link Parser** (`_fetch_link_content` or similar):
   - Check if link fetching is implemented
   - Verify it extracts content from URLs provided by users
   - Test with various URL types (articles, docs, etc.)
   - Check timeout and error handling

3. **Integration with Research Flow**:
   - Verify `user_materials` parameter is properly passed through the research pipeline
   - Check that parsed content is included in LLM prompts for research
   - Test end-to-end with actual uploads

### Affected Files
- `backend/app/services/agents/topic_researcher.py`
- Related utility modules for file/URL parsing

### Priority
High - affects research quality when users provide source materials

### Test Strategy
- Unit tests for PDF parsing with sample files
- Unit tests for URL fetching with mock responses
- Integration test: upload PDF + provide links → verify content appears in research context
